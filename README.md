# chemwise_calculator_app
ChemWise is a Python-powered chemistry toolkit built with Streamlit. It simplifies molar mass, percentage composition, mass-mole conversions, particle calculations, and element information lookup. Developed by Adenuga Aminat Aderonke, Chemist | Educator | AI &amp; Materials Researcher.
# ChemWise — A Smart Chemistry Toolkit

A Python-powered chemistry calculator built with Streamlit.

## Features
- Molar mass calculation
- Percentage composition
- Mass and mole conversions
- Particle calculations
- Element information lookup
